# 🐦 Flappy Bird (Python + Pygame)

Um clone simples do clássico Flappy Bird feito em Python usando Pygame.  
Projeto criado para praticar lógica de programação, eventos e desenvolvimento de jogos.

---

## 🎮 Como funciona

Você controla o personagem e precisa desviar dos canos.  
Cada cano passado = +1 ponto.

---

## 🚀 Como rodar o projeto

### 1. Clone o repositório
```bash
git clone https://github.com/joaonicolashahaha/Flappy-Bird.git
cd Flappy-Bird
python main.py
```
### Se python main.py NÃO funcionar você pode usar 
```bash
python3 main.py
